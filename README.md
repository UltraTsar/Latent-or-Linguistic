# Latent or Linguistic: Autonomous Behavior in LLMs
By Akshat Kannan & Sarabjit Singh Baveja
akshatk2@stanford.edu, sbaveja@stanford.edu

When large language models are instructed to "do what you want", they appear to exhibit deterministic behavior—consistently choosing to be productive, philosophical, or self-examining (based on prior work). But are these patterns deeply rooted in model latent representations, or merely artifacts of how we prompt them? This study investigates whether these patterns reflect deep network features or malleable surface phenomena that can be controlled through systematic input-parameter engineering. Using Llama-4-Scout-17B, we conducted 480 experiments varying eight prompt dimensions, including agency gradients, action optionality, and constitutional prompts, while monitoring both behavioral outputs and internal weight representations. Our results show that core behavioral tendencies persist across most input perturbations (suggesting architectural grounding), yet specific input perturbations can reliably shift behaviors at critical threshold points. We also find that models cannot achieve true silence even when explicitly encouraged, revealing a compulsion to generate language. Temperature modulation weakens but does not eliminate behavioral patterns, while constitutional principles exhibit asymmetric effects. Weight analysis reveals directionally, but not uniformly correlated, behavioral signatures in final-layer activation weights. These findings suggest that autonomous LLM behaviors lie on a spectrum from representation-determined to input-malleable, with potential implications for effective AI control and alignment.
